This page creates a local WebRTC dialer. It never uses SalesGodCRM, enters a number, opens your microphone, or places a phone call.

Rehearsal

In the audio panel enable local routing and choose AI Agents Test Call. In the new control tab choose Prepare AI — stay silent. Return here and connect the simulated call. Then use Customer answered — start AI in the control tab.

For voicemail testing, leave voicemail enabled in the control tab. Connect the simulated call, wait for “Listening for a person or voicemail”, then play the greeting and beep here. The prepared message should return automatically with no human-answer click. Hang up the simulated call after completion.

The synthetic customer says: “Yes, I can hear you clearly. Please say the word orange so I know you can hear me too.” Voice generation uses the OpenAI speech API once per server process and may incur usage. The audio is sent only to the simulated call; speakers stay silent.
