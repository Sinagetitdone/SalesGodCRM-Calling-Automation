SALESGODCRM / BROWSER AUDIO SETUPNo dialing controls

Connect without a cable.

The custom Chrome extension routes browser audio through a local setup window. No Windows audio driver is required.

1. Keep your key on this computer

Enter OPENAI_API_KEY in the local .env file in your repository folder, then restart the audio setup server. Never enter a key in GitHub, the extension, or AGENTS.md.

Open the standalone AI voice test →

This test requests one short AI introduction, measures received audio, and disconnects. It never opens your physical microphone or places a phone call. API usage may be billed.

2. Load the updated extension

In Chrome, open chrome://extensions, enable Developer mode, and load or reload SalesGod Local Audio Bridge version 0.3.0 from:

tools/audio-extension (inside your repository checkout)

Refresh SalesGodCRM only while its dialer is idle. The extension starts with routing disabled. It has no dialing controls, API keys, or broad browser permissions.

3. Check the idle audio connection

Keep the number field empty. In the extension panel, enable local routing and select Open AI voice setup. The new local window pairs with that page only.

Use Test paired routing without OpenAI first. It checks synthetic audio in both directions without an API request. Reopen the setup window to run Test paired AI connection with a working key.

Both tests disconnect automatically. A new dialer connection immediately stops setup mode. Actual telephone audio, sales conversations, and voicemail are not enabled.

Local test lab

Open the local audio test lab →

The lab loads the exact audio code without requiring an extension reload. A passing lab test does not establish that SalesGodCRM acquires the generated microphone during a phone call.

4. Supervised first call

In the idle CRM's extension panel choose Prepare supervised call, then Prepare AI — stay silent in the new control tab. Select the generated microphone in CRM. The owner or browser operator starts the authorized phone call using CRM.

Once connected audio and the generated microphone are verified, confirm a person answered before selecting Customer answered — start AI. The AI identifies itself and conducts a brief audio test. Pause or stop at any time; end the phone call separately in CRM. There is a five-minute AI session limit.

Rehearse a conversation without a phone call →

Event metadata is stored locally for seven days. No transcripts, recordings, contact details, or keys are logged.
