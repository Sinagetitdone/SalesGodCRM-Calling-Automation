Connect without a cable.

The custom Chrome extension routes browser audio through a local setup window. No Windows audio driver is required.

1. Keep your key on this computer

Enter OPENAI_API_KEY in the local .env file in your repository folder, then restart the audio setup server. Never enter a key in GitHub, the extension, or AGENTS.md.

Open the standalone AI voice test →

This test requests one short AI introduction, measures received audio, and disconnects. It never opens your physical microphone or places a phone call. API usage may be billed.

2. Load the extension

In Chrome, open chrome://extensions, enable Developer mode, and load or reload SalesGod Local Audio Bridge version 0.4.0 from:

tools/audio-extension (inside your extracted package or repository)

Refresh SalesGodCRM only while its dialer is idle. Routing starts disabled. The extension has no API key storage or broad browser permissions. Its calling-list adapter only dials after an explicitly authorized live Start.

3. Check the idle audio connection

Keep the number field empty. In the extension panel, enable local routing and select Open AI voice setup. The new local window pairs with that page only.

Use Test paired routing without OpenAI first. It checks synthetic audio in both directions without an API request. Reopen the setup window to run Test paired AI connection with a working key.

Both tests disconnect automatically. A new dialer connection immediately stops setup mode. These setup tests never place telephone calls.

Local test lab

Open the local audio test lab →

The lab loads the exact audio code without requiring an extension reload. A passing lab test does not establish that SalesGodCRM acquires the generated microphone during a phone call.

4. Try a simulated calling list

In the idle CRM extension panel choose Open calling list. Keep Simulation only checked, choose Use simulated contacts, then import, preview and start. Simulation makes no phone calls or OpenAI requests. Open controls through the extension to pair with CRM.

Live calling requires an approved contact list, the caller number assigned to your account, a reviewed conversation brief and voicemail, an allowed calling window, and explicit Start. The current live identity is an AI assistant from Jay Marketing Lab on behalf of Cena; review this before use. Keep CRM and the paired window open. The five-minute AI session limit applies.

Open the separate supervised audio rehearsal →

Calling-list contacts, transcripts and events stay in this computer's local databases for seven days of inactive retention; suppressions persist. No audio recordings or keys are logged. Export transcripts and events from the calling-list window. A no-call check cannot prove telephone audio or real response latency.
