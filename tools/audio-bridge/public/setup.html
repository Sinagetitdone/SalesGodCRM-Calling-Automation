Connect without a cable.

The custom Chrome extension routes browser audio through a local setup window. No Windows audio driver is required.

1. Keep your key on this computer

Enter OPENAI_API_KEY in the local .env file in your repository folder, then restart the audio setup server. Never enter a key in GitHub, the extension, or AGENTS.md.

Open the standalone AI voice test →

This test requests one short AI introduction, measures received audio, and disconnects. It never opens your physical microphone or places a phone call. API usage may be billed.

2. Load the extension

In Chrome, open chrome://extensions, enable Developer mode, and load or reload SalesGod Local Audio Bridge version 0.4.1 from:

tools/audio-extension (inside your extracted package or repository)

Refresh SalesGodCRM only while its dialer is idle. Routing starts disabled. The extension has no API key storage or broad browser permissions. Its calling-list adapter only dials after an explicitly authorized live Start.

3. Check the idle audio connection

Keep the number field empty. In the extension panel, enable local routing and select Open AI voice setup. The new local window pairs with that page only.

Use Test paired routing without OpenAI first. It checks synthetic audio in both directions without an API request. Reopen the setup window to run Test paired AI connection with a working key.

Both tests disconnect automatically. A new dialer connection immediately stops setup mode. These setup tests never place telephone calls.

4. Hear two AI agents rehearse a conversation

Open AI Agents Test Call and Live AI rehearsal →

In Rehearsal setup, choose Use simulated contacts, select Live AI rehearsal, then import, preview and choose Start rehearsal. An office AI and a fictional customer respond to each other with live text and two distinct voices. This uses OpenAI API credits but never places phone calls or needs the CRM. Choose Offline workflow check for free canned replies without audio.

Replay/download rehearsal audio before refreshing or closing the window. Text transcripts and list events are saved locally for seven days. Live telephone calls are not recorded. Rehearsal tests dialogue, not telephone routing, voicemail detection or interruptions.
