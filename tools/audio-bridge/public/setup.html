JAY MARKETING LAB / TWILIOSetup never calls anyone

Your Twilio calling desk.

Twilio handles dialing, telephone audio, answer detection and recordings. OpenAI provides the live AI conversation and your approved voicemail voice. The SalesGodCRM extension is no longer needed for calling.

1. Save credentials locally

Open the .env file in this installation folder. Set these values, save, and restart the bridge. Never put keys in GitHub, AGENTS.md, this page or an extension.

OPENAI_API_KEY=your OpenAI key
OPENAI_REALTIME_MODEL=gpt-realtime-2.1
TWILIO_ACCOUNT_SID=your Account SID
TWILIO_AUTH_TOKEN=your Auth Token
TWILIO_FROM_NUMBER=your Twilio number
TWILIO_PUBLIC_URL=
TWILIO_TUNNEL=quick

2. Connect the public audio address

Twilio must reach this computer over HTTPS and WSS. With TWILIO_TUNNEL=quick and no public URL, startup prepares a temporary Cloudflare connection automatically. Quick connections are for testing and may be unavailable. For dependable daily use, have IT provide a stable HTTPS/WSS tunnel forwarding to http://127.0.0.1:28432; set its public HTTPS origin as TWILIO_PUBLIC_URL, set TWILIO_TUNNEL=manual, then restart.

Port 28432 accepts only Twilio-signed callbacks and media for existing call attempts. Keep the private calling desk on 28431 local to this computer. Keep the bridge and tunnel running for the whole list. The setup guide includes Windows and Mac commands.

3. Check without dialing

Checking configuration…

Account type alone does not block calling. Normal lists require an owned voice-enabled caller; an explicitly started one-contact trial test can let Twilio validate the configured shared caller. Twilio may still reject trial numbers, recipients or features. This check does not buy numbers, upgrade your account or place a call.

4. Import and call when ready

Open calling lists →. Upload a CSV with first_name,last_name,phone, review the preview, background, guide and voicemail, and select your Twilio calling number. Create a draft, select it, then press Start selected list once. Pause finishes the current contact. Stop ends it. Existing lists with an old CRM caller number must be copied into a new draft with the Twilio number.

The backend continues if you close this page. Reopen Calling lists to see the active list and controls. Keep the bridge and tunnel running. Calls, recordings and AI usage may be billed.

Previous Conversations → contains local names, outcomes, transcripts, recordings and event logs. Twilio also retains call logs and recordings under your Twilio account settings. Deleting a local conversation does not delete the Twilio copy.
