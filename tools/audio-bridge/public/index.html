Connect without a cable.

The custom Chrome extension provides browser-only audio routing. No Windows audio driver is required.

Disconnected · Diagnostic versionOpenAI is not connected

1. Load the local extension

In Chrome, open chrome://extensions, enable Developer mode, and choose Load unpacked. Select this folder:

tools/audio-extension (inside your repository checkout)

The extension runs only on SalesGodCRM and the local test lab. It starts with routing disabled and has no OpenAI requests or phone-call controls.

2. Test the idle dialer

Refresh the SalesGodCRM dashboard after loading the extension. Confirm there are no ongoing calls. Enable local routing using the added diagnostic panel, then run its local audio test.

In the dialer's audio Settings, refresh devices and look for SalesGod AI Bridge (local audio). Keep the number field empty.

Seeing the device in the selector is separate from the dialer requesting its audio stream. Neither proves actual telephone audio. Restore the previous microphone and disable local routing after the test.

3. OpenAI voice comes later

This extension version is a local proof of concept. Once the dialer connection is verified and your API key is available, the next version can connect the audio streams to OpenAI. No key is needed for the current tests.

Local test lab

The lab exercises the extension's exact audio code without installing it. A passing lab test does not establish that SalesGodCRM accepts the generated microphone.
