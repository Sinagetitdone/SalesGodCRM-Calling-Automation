Calling Automation Demo

Walk through how a contact list becomes calls, one check at a time.

Demo only. The contacts are synthetic (reserved 555-01XX numbers) and the calling provider is a fake. No real calls are placed.

How a contact moves through the system

  1. 1Each row is checked for a valid US phone number and for duplicate numbers.
  2. 2The number is checked against the do-not-call list you provide.
  3. 3A consent record must exist for that contact and number. It must cover automated calls, must not be revoked, and must already be in effect.
  4. 4Accepted contacts go to the call orchestrator. It checks the calling window and then dispatches the call to the provider.
  5. 5Each call is saved. Running the same import again returns the existing call and does not dial again.
