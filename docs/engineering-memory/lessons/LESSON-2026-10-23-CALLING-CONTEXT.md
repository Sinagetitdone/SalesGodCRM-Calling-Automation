# Saved context must reach every actual audio path

A settings form is insufficient unless the real session request and opening message use its saved context. Keep reusable defaults separate from campaign snapshots and retention; changing defaults must not rewrite an active attempt. Validate minimum/maximum lengths after trimming in the backend as well as the editor, and test exact bounds and restart persistence.

Voice selection spans the live Realtime session, prepared voicemail speech, manual call controls and both rehearsal roles. Keep the server allowlist shared, propagate the selected voice through the worker, and test outbound payloads for every option. Labels and transcript role badges must reflect saved settings rather than old hardcoded voice names. Style/age directions are approximate instructions, not properties guaranteed by a voice ID. Verify payload behavior without dialing; do not claim recipient-side sound or perceived age from mocked tests.
