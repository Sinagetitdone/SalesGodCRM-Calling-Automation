# LL-2026-009: Distribute an allowlisted build, not an installed workspace

A local audio bridge accumulates keys, contact/transcript databases, suppression state, screenshots and exports beside its source. A recursive ZIP of the working folder can disclose those records even when Git ignores them. Distribution therefore needs its own explicit file allowlist and a generated blank environment template. Never read the owner's .env to build that template. Exclude installed dependencies and runtime data; ship a production-only lockfile and install it on each colleague's machine.

Platform launchers are deployment code. Test from an independently extracted archive in a path with spaces, preserve existing configuration through exclusive creation, detect occupied ports without killing other processes, and keep phone actions behind explicit Start. Normalize Mac shebang files to LF even on Windows Git checkouts, and set executable ZIP attributes. Validate archive contents, checksums, clean dependency installation, required asset routes and simulation defaults. A passing shell syntax check does not establish Mac Finder/Gatekeeper behavior or telephone audio; document those evidence limits. Do not redistribute an installation after it has been configured with real credentials or contacts.
