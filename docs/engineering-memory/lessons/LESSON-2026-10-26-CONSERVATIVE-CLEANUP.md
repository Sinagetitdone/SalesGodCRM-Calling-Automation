# Preserve observable behavior during calling-system cleanup

Extract pure parsing, mappings and decisions before reorganizing asynchronous media paths. Keep public exports and stored state values compatible. Named timeouts should describe the operation and unit; sharing a number does not mean two deadlines are the same policy.

Call outcomes encode evidence precedence. Compare the old and new decision over combinations of takeover, voicemail, opt-out, transcript, time-limit and phone state, then keep readable scenario tests for those priorities. Avoid replacing descriptive state strings with numeric enums when the strings already form an explicit contract.

New local modules must be added to the distribution allowlist. Validate packaged relative imports, not just the source checkout. Use synthetic dialer tests and no-phone browser rehearsals to cover integration without accidentally enabling real calls.

See `docs/CODE-CLEANUP-0.6.1.md` for the verified scope and limits.
