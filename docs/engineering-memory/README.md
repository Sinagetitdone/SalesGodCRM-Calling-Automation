# Engineering Memory

Engineering Memory stores reusable lessons and bugs as atomic Markdown records with YAML front matter.

## Canonical sources

- lessons/: reusable lessons.
- bugs/: recurring or important bugs and mistakes.
- taxonomy.yml: controlled taxonomy.
- index.json: generated index; not canonical.
- LESSONS_LEARNED.md: curated summary.
- COMMON_BUGS_AND_MISTAKES.md: curated summary.
- templates/: record templates.

## Rule

Record a lesson when a discovery, failure, or implementation decision is likely to prevent repeated work or error.

Do not record secrets, credentials, or unnecessary personal data.
